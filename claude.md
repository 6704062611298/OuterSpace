# OuterSpace

Pure Java top-down space shooter + roguelite.

## Project Rules

- This project uses pure Java.
- Do not use external game engines or frameworks.
- Do not introduce JavaFX, LibGDX, Unity, or Unreal.
- Use the Java standard library unless explicitly requested otherwise.

## Documentation

Read when relevant:

- Docs/GAME_DESIGN.md

## Development Rules

1. Inspect existing code before modifying it.
2. Do not duplicate existing functionality.
3. Keep classes focused on one responsibility.
4. Prefer simple solutions.
5. Avoid unnecessary design patterns.
6. Do not implement features that were not requested.
7. Compile and test after significant changes.
8. Update TODO.md when a major feature is completed.
